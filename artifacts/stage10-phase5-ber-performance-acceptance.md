## 实现范围

扩展现有 Stage10，不新增重复页面。后端 `run_eb_n0_sweep` 复用生产 `run_experiment`，新增 `POST /api/stage10/ber-sweep`；前端增加扫描表单、公共 `ChartFrame` 曲线、统计表和本轮数据教学复盘。Stage01–09、卷积编码器和 Viterbi 实现未改。

扫描默认 0–10 dB、步长 2 dB、2048 信息位/点、seed 2026。限制：最多 16 点、4096 位/点、32768 总信息位。点序严格递增并含两端。每点以根 seed、点索引、域标签派生子 seed，使用独立 payload 与噪声；每个点单次实验，不筛选、不重试 seed。

## 数学与统计契约

保留 K=3、(7,5)、R=1/2、(g0,g1)、两个零尾位、终止式硬判决 Viterbi 与固定信息位 Eb/N₀ 公平能量口径。编码 BER 统计含尾位的全部码位；未编码和译码后 BER 各统计原始信息位。所有 BER 由该点误码数/对应统计分母计算，不跨百分比简单平均。噪声方差随 Eb/N₀ 按生产实现计算。零误码结果保留 BER=0；有限样本未观察到错误不代表真实 BER 为零。

## API 与 HTTP 实测

`POST /api/stage10/ber-sweep` 接受 `start_db`、`stop_db`、`step_db`、`n_information_bits`、`seed`。使用真实 HTTP 请求测试成功响应、相同参数 seed 重放、非法步长、超计算上限。合法请求返回 HTTP 200；非法和超限请求均返回 HTTP 422，参数错误由验证层给出，不暴露内部堆栈。相同 0–4 dB、2 dB 步长、64 位、seed 2026 的重复响应完全一致。真实响应噪声方差为 0.5、0.3154786722400966、0.19905358527674863。

API 返回每点 Eb/N₀、实际子 seed、噪声方差以及三类误码数、各自比较分母和 BER。扫描点与生产函数直接结果的等价由新增 API/生产核心测试验证。
